# האתר של הסדנה "Claude, השותף החדש שלך"

אתר סטטי (HTML, CSS ו־JavaScript בלי שלב בנייה) עם שלושה חלקים:

| קובץ | מה זה |
|---|---|
| `index.html` | דף הנחיתה: פתיח, הסדנה, סילבוס, שחר, מחיר והרשמה, טופס שאלות |
| `portal.html` | אזור המשתתפים: כניסה עם קוד, המפגש הבא, הקלטות, חומרים וסט ה־Skills |
| `admin.html` | עמוד עזר לעדכון ההקלטות והחומרים (לא מופיע בתפריט ולא באינדקס של גוגל) |

כללי העיצוב מתועדים ב־`DESIGN.md`.

## הרצה מקומית

```bash
python3 -m http.server 8000
```

ואז לפתוח את http://localhost:8000. חייבים שרת: פתיחה ישירה של הקובץ לא תטען את תוכן הפורטל.

## פרסום ב־GitHub Pages

1. בגיטהאב: Settings ← Pages.
2. תחת Source בוחרים Deploy from a branch, את הענף ואת התיקייה `/ (root)`.
3. אחרי דקה־שתיים האתר עולה בכתובת שמופיעה שם. אפשר לחבר דומיין משלכם באותו מסך.

## הגדרות לפני ההשקה: `assets/js/config.js`

| שדה | מה שמים |
|---|---|
| `registerUrl` | קישור לדף התשלום או טופס ההרשמה. ריק = כפתורי ההרשמה מובילים לטופס השאלות |
| `contactEndpoint` | כתובת Formspree (או שירות דומה) שתקבל את טופס השאלות. ריק = נפתח מייל |
| `contactEmail` | המייל שאליו נשלחות פניות כשאין `contactEndpoint` |
| `linkedinUrl` | הקישור לפרופיל הלינקדאין. ריק = הקישור מוסתר |
| `intro` | `false` מבטל את הפתיח |
| `introVideo` | נתיב סרטון הפתיח. אם הקובץ חסר, מוצג הפתיח המצויר |

## העלאת הקלטות וחומרים אחרי כל מפגש

1. מעלים את ההקלטה ל־YouTube כ"לא רשום" (Unlisted) או ל־Vimeo עם הגדרת פרטיות מתאימה, ומעתיקים את הקישור.
2. קבצים (מצגת, PDF, קובצי Skill): מעלים לתיקייה `assets/materials/` בגיטהאב, או ל־Google Drive עם הרשאת צפייה בקישור.
3. פותחים את `admin.html` באתר, מדביקים את הקישורים ולוחצים "הורדת course.json".
4. בגיטהאב מחליפים את `content/course.json` בקובץ שירד (Add file ← Upload files). האתר מתעדכן תוך דקה.

אפשר גם לערוך את `content/course.json` ישירות. לכל מפגש יש `zoomUrl`, `recording` (`type`: youtube / vimeo / drive / file, ו־`url`) ו־`materials` (רשימה של `title`, `url`, `kind`).

## קוד הכניסה לפורטל

- הקוד הזמני הוא **`LEVELUP2026`**. מחליפים אותו לפני שהקוד יוצא למשתתפים.
- להחלפה: ב־`admin.html` כותבים קוד חדש בשדה "קוד חדש", מורידים את `course.json` ומחליפים כמו בהעלאת הקלטות. בקובץ נשמר רק גיבוב (hash) של הקוד.

**חשוב לדעת:** קוד משותף הוא הגנה קלה, שמרחיקה מבקרים מזדמנים, ולא אבטחה אמיתית. מי שמכיר את הקישור הישיר להקלטה יכול לצפות בה. לכן ההקלטות צריכות להיות "לא רשומות" או מוגנות בדומיין ב־Vimeo. אם בעתיד תרצו כניסה אישית לכל משתתף, אפשר להוסיף שירות כמו Supabase או Memberstack.
