# מצגות המפגשים

כל מפגש בתיקייה משלו: `slides/session-1/`.

- **להצגה:** פותחים את `index.html` בדפדפן, דרך שרת (`python3 -m http.server 8765` מתיקיית השורש) או מהאתר המפורסם.
  - **מעבר בין שקפים:** חץ שמאלה או רווח קדימה, חץ ימינה אחורה. Home ו־End מגיעים להתחלה ולסוף.
  - **הערות דובר:** מקש N.
  - **מסך מלא:** מקש F.
  - **שקף מסוים:** מוסיפים לכתובת `#7`.
- **PDF:** `node slides/session-1/build-pdf.cjs` (עם שרת פתוח) כותב את `session-1.pdf`: שקף בכל עמוד, כפי שהוא נראה בסוף האנימציות.
- **בפרסום ב־claude.ai כ־Artifact:** הנתיבים `../../assets/` מוחלפים ב־`assets/`, כי שם המצגת יושבת בשורש.
- **מקורות:** כל עובדה בשקפים מבוססת על עמוד רשמי של Anthropic, וכל שקף מציין את המקור שלו. המחקר המלא, עם קישורים, נמצא ב־`RESEARCH.md` (נבדק ב־7.11.2026). מוצרים ומחירים משתנים, אז כדאי לבדוק שוב לפני כל מחזור.
- **באזור המשתתפים:** בשדה "קישור למצגת" בעמוד הניהול כותבים `slides/session-1/index.html`. המצגת תוצג בתוך עמוד המפגש, עם האנימציות.
- **עיצוב:** `deck.css` משתמש באותם פונטים, צבעים ומסגרות עיפרון של האתר (`assets/js/sketch.js`). הדמויות נמצאות ב־`assets/img/`.
